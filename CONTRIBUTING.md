# Вклад в проект

Спасибо за интерес к участию в развитии этого проекта! Мы приветствуем все виды вклада: баг-репорты, идеи фич, pull requests.

## Как начать

1. **Форкните** репозиторий
2. **Клонируйте** свой форк
3. **Создайте ветку** для изменений (`git checkout -b feature/awesome-idea`)
4. **Внесите изменения** и закоммитьте
5. **Отправьте** в свой форк (`git push origin feature/awesome-idea`)
6. **Создайте Pull Request** в основной репозиторий

## Сообщения о багах

Прежде чем создать issue:
- Проверьте, не был ли этот баг уже зарегистрирован
- Включите версию Python, ОС и шаги воспроизведения
- Прикрепите логи, если они релевантны

## Pull Requests

- Делайте PR направленными — одна фича или фикс за PR
- Описывайте **что** и **почему** вы изменили
- Убедитесь, что код запускается без ошибок
- Пишите понятные commit-сообщения на английском

## Стиль кода

- Следуйте PEP 8
- Используйте type hints
- Документируйте публичные функции docstring'ами
- Логируйте важные события

## Локальное тестирование

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# Вставьте BOT_TOKEN в .env
python -m bot.main
```
