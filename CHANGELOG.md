# История изменений

## [1.3.0] — 2026-07-28

### Добавлено
- Поддержка VK Видео, Клипов и медиапостов.
- Поддержка обычных YouTube-видео и дополнительных площадок через `yt-dlp`/`gallery-dl`.
- Instagram-посты, фото и смешанные карусели.
- Анонимный Instagram-extractor через публичные embed-страницы и `curl-cffi`.
- Опциональные proxy и TLS-имперсонация для площадок с ограничением гостевого доступа.
- Проверка итоговых потоков через `ffprobe` и совместимости с Telegram.

### Исправлено
- Если площадка отдала видео без звука при наличии аудиоформата, дорожка скачивается отдельно и добавляется через `ffmpeg`.
- Некомпатибельные контейнеры и кодеки нормализуются в MP4/H.264/AAC.
- Фото-посты больше не скачивают и не отправляют отдельную аудиодорожку.
- Публичные Instagram-посты и Reels больше не требуют cookies браузера.

## [1.2.0] — 2026-07-02

### Добавлено
- Поддержка скачивания Instagram Reels.
- Отправка аудиофайла вместе с фото-постами TikTok, если звуковая дорожка доступна.

### Исправлено
- Выбор video+audio формата в `yt-dlp`, чтобы видео не скачивались без звука.
- Поиск фактически созданного файла после скачивания, если `yt-dlp` сохраняет не строго `media_id.mp4`.

## [1.1.0] — 2026-05-12

### Добавлено
- Настройки чата через `/settings` (только для админов)
- Флаг **«Только чистые ссылки»** — бот отвечает только на чистые ссылки
- Флаг **«Удалять сообщения со ссылками»** — автоудаление исходных сообщений
- Переменная `AUTO_ALLOW_MEMBER_CHATS` — выбор режима работы бота
- Таблица `chat_settings` в базе данных
- Полноценная миграция Alembic для новой таблицы

### Изменено
- README полностью переписан на русский
- Добавлены файлы для сообщества: CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, CHANGELOG
- Улучшена структура `.gitignore`
- Удалены неиспользуемые скрипты запуска (`run.bat`, `run.sh`, `setup.sh`)

## [1.0.0] — 2026-04-27

### Добавлено
- Скачивание видео из TikTok без водяных знаков
- Поддержка YouTube Shorts
- Inline-режим работы в любом чате
- Статистика пользователей (`/stats`)
- Rate limiting
- Автоочистка временных файлов
- База данных SQLite с Alembic-миграциями
- Docker-контейнеризация
- Systemd unit для Linux
