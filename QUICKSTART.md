# Быстрый старт TikTok Downloader Bot

## Шаг 1: Создать бота в Telegram

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`
3. Придумайте имя для бота (например: "My TikTok Downloader")
4. Придумайте username (например: "my_tiktok_bot")
5. Скопируйте токен (примерно так: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

## Шаг 2: Включить inline режим

1. В [@BotFather](https://t.me/BotFather) отправьте `/setinline`
2. Выберите вашего бота
3. Введите: `Вставьте ссылку на TikTok видео`

## Шаг 3: Установить команды (опционально)

1. В [@BotFather](https://t.me/BotFather) отправьте `/setcommands`
2. Выберите вашего бота
3. Вставьте:
```
start - Начать работу с ботом
help - Помощь и инструкции
stats - Моя статистика
```

## Шаг 4: Настроить бота

### Windows

1. Откройте папку проекта
2. Скопируйте `.env.example` → `.env`
3. Откройте `.env` в блокноте
4. Замените `your_bot_token_here` на ваш токен
5. Сохраните файл
6. Запустите `run.bat`

### Linux/Mac

1. Откройте терминал в папке проекта
2. Выполните: `./setup.sh` (автоматическая настройка)
3. Или вручную:
   ```bash
   cp .env.example .env
   nano .env  # Вставьте токен
   ./run.sh
   ```

## Шаг 5: Проверить работу

1. Найдите вашего бота в Telegram
2. Отправьте `/start`
3. Попробуйте inline режим:
   - Откройте любой чат
   - Напишите `@your_bot https://www.tiktok.com/@user/video/123`
   - Выберите результат

## Готово! 🎉

Бот работает и готов скачивать видео.

## Если что-то не работает

### Бот не запускается

- Проверьте, что токен правильно вставлен в `.env`
- Убедитесь, что Python 3.10+ установлен
- Посмотрите логи в файле `bot.log`

### Inline режим не работает

- Убедитесь, что выполнили Шаг 2 (включили inline в BotFather)
- Перезапустите бота
- Подождите несколько минут (Telegram может кэшировать)
