## 🚀 Основные функции

### 1. Inline режим (главная фича!)
- ✅ Работает в ЛЮБОМ чате без добавления бота
- ✅ Пользователь пишет `@botusername ссылка`
- ✅ Видео отправляется в личные сообщения
- ✅ Поддержка всех форматов TikTok ссылок

### 2. Скачивание видео
- ✅ Без водяных знаков через yt-dlp
- ✅ Высокое качество (best available)
- ✅ Проверка размера файла (макс 50 МБ)
- ✅ Асинхронная загрузка
- ✅ Обработка ошибок (недоступно, приватное и т.д.)

### 3. Автоматическая очистка
- ✅ Удаление файлов сразу после отправки
- ✅ Фоновая задача каждые 15 минут
- ✅ Удаление "зависших" файлов старше 10 минут
- ✅ Логирование операций очистки

### 4. База данных SQLite
- ✅ Таблица users (пользователи)
- ✅ Таблица downloads (история загрузок)
- ✅ Таблица statistics (агрегированная статистика)
- ✅ Асинхронные операции через aiosqlite

### 5. Статистика
- ✅ Личная статистика по команде /stats
- ✅ Счетчик скачанных видео
- ✅ Общий размер скачанных файлов
- ✅ Дата последнего скачивания
- ✅ Дата регистрации в боте

### 6. Rate Limiting
- ✅ Максимум 5 запросов в минуту на пользователя
- ✅ In-memory хранилище запросов
- ✅ Автоматическая очистка старых записей
- ✅ Уведомление при превышении лимита

### 7. Команды бота
- ✅ `/start` - приветствие и инструкция

## 🎯 Как запустить

### Windows
1. Создать бота в @BotFather
2. Включить inline режим: `/setinline`
3. Скопировать `.env.example` → `.env`
4. Вставить токен в `.env`
5. Запустить `run.bat`

### Linux/Mac
1. Создать бота в @BotFather
2. Включить inline режим: `/setinline`
3. Выполнить: `./setup.sh`
4. Запустить: `./run.sh`

### VPS (Production)
1. Скопировать проект на сервер
2. Выполнить `./setup.sh`
3. Скопировать `tiktok-bot.service` в `/etc/systemd/system/`
4. Выполнить:
   ```bash
   sudo systemctl enable tiktok-bot
   sudo systemctl start tiktok-bot
   ```
